Проходные изоляторы
Дыра в стене
<&feedthrough>Провода сами по себе не могут сосуществовать с камнем, или деревом, или более промышленными материалами, блокирующими их путь.<br>
С помощью тщательного применения изоляции из терракоты, твёрдый канал может быть сконструирован внутри этих материалов для проведения энергии.<br>
Проходной изолятор позволяет объединить два разъёма через стены толщиной в один метр, и не может подключать более одного провода на разъём.<br>
Они могут быть созданы с любым "нормальным" твёрдым блоком посередине, щёлкнув правой кнопкой мыши по любому из двух разъёмов инженерным молотком.<br>
Неструктурные разъёмы могут использоваться для создания проходных изоляторов для соответствующего типа провода.
