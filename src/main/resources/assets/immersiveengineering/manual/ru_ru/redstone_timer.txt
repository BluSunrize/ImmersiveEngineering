Редстоуновый таймер
Тик-так, тик-так!
Таймер - это редстоуновое устройство, которое использует колеблющийся кварцевый кристалл для выдачи сигнала через регулярные промежутки времени.<br>
Держа инженерную отвертку и нажимая правую кнопку мыши по таймеру, можно настроить его интервал и цвет выходного сигнала.<np>
Кроме того, таймер можно настроить так, чтобы он требовал контролирующий сигнал, он не будет работать без подачи этого сигнала.
