Машинный интерфейс
Быстро к сложному
<&recipe>С усложнением многоблочных машин, отслеживать их потребности становится все сложнее.<br>
В то время как <link;redstone_probe;компаратор сигналы> могут дать некоторое представление о количестве ресурсов внутри, только машинный интерфейс может обеспечить более подробную оценку и отправлять редстоун сигналы.<np>
При размещении на редстоуновой панели управления мультиблочной машины, открытие графического интерфейса позволит настроить различные условия для вывода сигнала.<br>
Нажмите кнопку "Добавить условие", чтобы добавить новую строку. В этой строке первая кнопка служит для удаления условия, а вторая - для настройки цвета сигнала, который будет выводиться.<np>
За этим следуют два выпадающих меню, одно из которых предназначено для выбора проверки (например, "Машина активна", "Ввод ресурсов", "Вывод жидкости"), а другое для выбора условия.<br>
Большинство проверок поддерживают "сигнал компаратора" для определения уровня сигнала, который масштабируется в соответствии с запасенными продуктами/жидкостью/энергией. Также существуют различные варианты истинно или ложно, такие как "75% Заполнено" или "Пусто".<np>
Как только условие будет выполнено, машинный интерфейс выведет соответствующий цветовой сигнал через подсоединенный <link;redstone_wiring;редстоуновый интерфейсный коннектор;bundled>.<br>
Помимо вывода, машинный интерфейс может также принимать редстоун сигнал и выводить его на подключенную машину. Цвет сигнала настраивается в правом нижнем углу графического интерфейса.<np>
Это позволяет использовать <link;logic_unit;системный блок> для оценки сигналов, поступающих от устройства, и последующей отправки, чтобы включить или отключить машину!
