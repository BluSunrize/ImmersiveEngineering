Машинный интерфейс
Быстрый запрос сложных условий
<&recipe>С возрастающей сложностью многоблочной техники отслеживание её потребностей становится довольно сложным.<br>
В то время как <link;redstone_probe;сигналы компаратора> могут предоставить некоторое представление о количестве предметов внутри, только машинный интерфейс может предоставить более детальную оценку и отправлять сигналы красного камня.<np>
При размещении против поверхности управления редстоуном многоблочной структуры, открытие интерфейса позволит настроить различные условия, по которым выводить сигнал.<br>
Нажмите кнопку "Добавить условие", чтобы добавить новую строку. В этой строке первая кнопка служит для удаления строки снова, вторая — для настройки цвета сигнала для вывода.<np>
За этим следуют два выпадающих меню, одно для выбора типа проверки (такой как "Машина активна", "Вход предметов", "Выход жидкости") и одно для выбора условия.<br>
Большинство проверок поддерживают "Выход компаратора" для силы сигнала, которая масштабируется к предметам/жидкости/энергии, хранящейся. Также существуют различные варианты истина или ложь, такие как "Заполнено на 75%" или "Пусто".<np>
Как только условие совпадает, машинный интерфейс выведет соответствующий сигнал на настроенном цветовом канале на любой прикреплённый <link;redstone_wiring;Интерфейсный разъём красного камня;bundled>.<br>
В дополнение к отправке, машинный интерфейс также может принимать сигнал красного камня и выводить его на подключённую машину. Цвет сигнала для этого настраивается в правом нижнем углу интерфейса.<np>
Это позволяет использовать <link;logic_unit;Логический блок> для оценки сигналов, поступающих от машины, а затем отправить один обратно, чтобы включить или отключить её!
