Дозатор предметов
Соберитесь вместе прямо сейчас
<&recipe>Дозатор предметов предназначен для сбора набора предметов с входящего конвейера перед их отправкой дальше, чтобы передавать в машины оптимальные размеры партий.<np>
В §2пакетном режиме§r входящие предметы будут приниматься в инвентарь прямо под фильтрами, а собранная партия будет выведена только когда все фильтры удовлетворены.<br>
Когда режим вывода устройства переключён в §2одиночный режим§r, вместо этого будет выведен любой предмет, удовлетворяющий заданному фильтром количеству.<br>
Соединения под фильтрами буфера задают целевой цвет <link;redstone_wiring;редстоунового провода> через подключённые <link;redstone_wiring;редстоуновые интерфейсные коннекторы;bundled>.<br>
Когда каждый отдельный фильтр удовлетворён, через коннектор будет отправлен сильный сигнал на настроенном цвете.<br>
Учтите: если несколько фильтров используют один и тот же цвет, для вывода сигнала должны быть удовлетворены все они.<br>
Эти сигналы можно использовать для настройки машин, дисплеев и других механизмов для управления целыми фабриками.
