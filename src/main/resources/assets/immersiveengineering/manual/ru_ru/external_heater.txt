Внешний нагреватель
Теперь вы готовите на флаксе!
<&recipe>Внешний нагреватель генерирует тепло из Флакса, которое он выводит на тепловые вентиляционные отверстия на своих боках.<br>
Он не может производить восстановительные атмосферы, используемые в доменных печах, дым от дерева для консервирования пищи или температуры, необходимые для печей.<br>
При размещении рядом с обычной печью эта тепловая энергия будет обеспечивать тепло печи без расхода топлива.<br>
Бока нагревателя могут быть настроены с помощью инженерского молотка, присядьте, чтобы нацелиться на противоположную сторону.<br>
Нагреватель будет потреблять 8 Флакс/т для каждой печи, которую нужно нагреть. Для предварительного нагрева печи потребуется в четыре раза больше, пока печь не наберёт температуру.<br>
Когда печь находится при максимальной температуре, внешний нагреватель будет потреблять всего §o32 Флакс/т§r на печь для увеличенной скорости плавки, если сигнал красного камня не отключает ускорение.<br>
Только печи, в которых есть предметы для плавки и место для их плавки, будут нагреваться.
