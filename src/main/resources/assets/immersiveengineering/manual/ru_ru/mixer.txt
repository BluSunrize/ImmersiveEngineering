Смеситель
Цистерны с тестом для печенья!
Смеситель — это многоблочная структура, которая растворяет твёрдые вещества в жидкостях, смешивая их вместе. Структура строится, как показано выше, и формируется с помощью инженерного молотка на центральном блоке листового металла.<np>
Наиболее распространённые использования этой машины — смешивание <link;concrete;жидкого бетона;liquid> или создание <link;industrial_fluids;жидких зелий;potion> из воды и их различных ингредиентов.<br>
Жидкости вводятся в смеситель через порт внизу источника питания. Предметы могут быть загружены через два люка сзади. Жидкостный порт спереди служит для вывода жидкости.<br>
Подача сигнала красного камня на панель управления спереди остановит процесс машины, это поведение может быть инвертировано с помощью инженерной отвёртки.
