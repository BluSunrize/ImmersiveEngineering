Внешний нагреватель
Теперь готовим на Flux!
<&recipe>Внешний нагреватель создаёт тепло из Flux и выводит его через тепловые вентиляционные отверстия по бокам.<br>
Он не может создавать восстановительную атмосферу, используемую в доменных печах, древесный дым для консервации пищи или температуры, необходимые для обжиговых печей.<br>
Если поставить его рядом с обычной печью, эта тепловая энергия будет нагревать печь без расхода топлива.<br>
Стороны нагревателя можно настраивать молотом инженера; приседание позволяет выбрать противоположную сторону.<br>
Нагреватель потребляет 8 Flux/t за каждую печь, которую нужно нагревать. Для предварительного разогрева печи потребуется в четыре раза больше, пока она не выйдет на рабочую температуру.<br>
Когда печь достигает максимальной температуры, внешний нагреватель потребляет всего §o32 Flux/t§r на печь для ускоренной переплавки, если редстоуновый сигнал не отключает усиление скорости.<br>
Нагреваются только печи, в которых есть предметы для переплавки и место для результата.
