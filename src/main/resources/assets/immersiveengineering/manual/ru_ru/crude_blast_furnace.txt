Примитивная доменная печь
Простая сталь
<&block>Эта печь используется для насыщения железа углеродом, превращая его в сталь.<br>
Для этого можно использовать только высокоуглеродистое топливо: <link;coke_oven;кокс или древесный уголь>.<np>
<&outputs>Вместе со сталью печь производит <link;industrial_byproducts;шлак>, который нужно удалять вручную, иначе печь остановится.<br>
Шлак полезен для <link;slag_products;кирпичей> или <link;concrete;бетона>.<np>
<&multiblock>Соберите блоки кирпича 3x3x3 и щелкните по центру боковой стороны инженерным молотом.<np>
Эта печь §lне§r автоматизируется. Все операции — через интерфейс. Для автоматизации соберите <link;improved_blast_furnace;улучшенную доменную печь>.
