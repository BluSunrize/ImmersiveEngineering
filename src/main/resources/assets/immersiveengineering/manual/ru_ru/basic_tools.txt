Основные инструменты
§mСерп§r Отвёртка и молот
<&engineers_hammer>Молот инженера — один из самых важных инструментов в наборе инженера.<br>
Его можно использовать для настройки и формирования машин, а также для дробления руд.<np>
<&wirecutters>§lКусачки инженера§r используются, чтобы снять все провода, подключённые к блоку, простым щелчком ПКМ по нему.<br>
Кусачками также можно снимать провода, натянутые между столбами, если использовать их на самом проводе.<np>
<&screwdriver>Отвёртки инженера — ещё один частый предмет в наборах инструментов.<br>
Они используются для точной настройки некоторых механизмов.<np>
<&multimeter>§lВольтметры инженера§r используются для измерения соединений.<br>
Если навести вольтметр на любое хранилище энергии или щёлкнуть по нему ПКМ, он покажет текущий запас энергии.<br>
Присядьте и щёлкните ПКМ по двум коннекторам, чтобы рассчитать средние потери между ними.<br>
Вольтметры также можно использовать для считывания уровня редстоуна у блоков, таких как редстоуновые коннекторы и редстоуновая пыль.
