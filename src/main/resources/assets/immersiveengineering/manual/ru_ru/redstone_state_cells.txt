Редстоун-ячейка состояния
4-битное хранилище
Ячейка состояния — это компонент для использования с <link;redstone_wiring;проводами из красного камня>. Они хранят входное значение и затем выводят это же значение до тех пор, пока не будут сброшены.<br>
Там, где ранее такие установки требовали несколько блоков компараторов или даже поршней, теперь возможно хранить значение в одной <link;crafting_components;электронной лампе;tubes>.<np>
Использование инженерной отвёртки на ячейке состояния открывает экран для настройки цветов сигналов Установки, Сброса и Вывода.<br>
§lУстановка: §rСигнал этого цвета сохраняется в ячейке состояния до тех пор, пока она не будет сброшена.
§lСброс: §rСигнал этого цвета сбрасывает ячейку состояния, позволяя установить её снова.
§lВывод: §rЭто цвет сигнала, на котором ячейка выводит своё значение.<br>
Когда сигналы Установки и Сброса настроены на один цвет, ячейка состояния будет работать как система переключения, где каждый раз при получении импульса этого цвета ячейка переключается между наличием выхода или отсутствием такового.
