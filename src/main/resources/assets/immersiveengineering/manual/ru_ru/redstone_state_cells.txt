Редстоуновая ячейка состояния
4-битное хранилище
Ячейка состояния — компонент для использования с <link;redstone_wiring;редстоуновыми проводами>. Она сохраняет входное значение и затем выводит это же значение, пока не будет сброшена.<br>
Если раньше для таких схем требовалось несколько компараторов или даже поршни, теперь значение можно хранить в одной <link;crafting_components;электронной лампе;tubes>.<np>
Использование отвёртки инженера по ячейке состояния открывает экран настройки цветов сигналов установки, сброса и выхода.<br>
§lУстановка: §rсигнал этого цвета сохраняется в ячейке состояния, пока она не будет сброшена.
§lСброс: §rсигнал этого цвета сбрасывает ячейку состояния, позволяя снова установить её.
§lВыход: §rэто цвет сигнала, на котором ячейка выводит своё значение.<br>
Если сигналы установки и сброса настроены на один цвет, ячейка состояния будет работать как переключатель: каждый раз при получении импульса этого цвета ячейка переключается между наличием выхода и его отсутствием.
