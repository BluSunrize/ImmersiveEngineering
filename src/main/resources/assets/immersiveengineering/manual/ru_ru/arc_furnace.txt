Дуговая печь
Не реактор
Дуговая печь — это массивная машина, используемая для быстрого сплавления металлов и плавки руд. Она состоит из опор и чана из стали и огнеупорного кирпича, увенчанного электродами для нагрева чана.<np>
Дуговые печи могут плавить партии из множества предметов одновременно, но мало быстрее своих <link;improved_blast_furnace;более простых сестёр> при большем потреблении энергии. Таким образом, они отличаются скоростью при больших заказах.<br>
В результате увеличения скорости на порядок величины благодаря параллельной плавке, дуговая печь — это сложная машина, требующая ручного обслуживания в виде замены электродов. Это обслуживание не может выполняться автоматически.<np>
После использования электродов примерно четыре непрерывных дня плавки они деградируют настолько, что ломаются.<br>
Для формирования структуры соберите её, как показано на первой странице, затем щёлкните по котлу инженерным молотком.<br>
Энергия подаётся через три разъёма сзади, а подача сигнала красного камня на панель управления спереди выключит машину.<br>
Выходные материалы собираются из бассейна в передней части структуры, шлак — через порт в центре сзади. Дуговая печь автоматически выталкивает выходные материалы и шлак в подключённые приёмники.<br>
Щелчок правой кнопкой мыши по панели, котлу или чану откроет интерфейс.<np>

Три слота сверху предназначены для <link;coke_and_graphite;графитовых электродов;shaping>.<br>
Двенадцать слотов слева — это входные слоты для металлов и руд. Рядом с каждым слотом есть индикатор температуры, показывающий прогресс плавки.<br>
Кнопка в верхнем левом углу экрана изменяет то, распределяются ли предметы по дуговой печи или концентрируются в одной точке чана.<br>
Четыре слота справа предназначены для "добавок" — различных материалов, добавляемых к расплавленному металлу в процессе крафта. Примером может служить добавление пыли кокса к расплавленному железу для создания стали.<br>
Входы и добавки вставляются через два люка сверху структуры: входы слева, добавки справа от электродов.<br>
Семь слотов снизу — это шесть выходных слотов и слот для шлака в нижнем правом углу.
