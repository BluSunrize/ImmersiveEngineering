Роторный экскаватор
Конкурент дворфам
<&full>Роторный экскаватор - это одна из вершин современной промышленности, способная выкапывать <link;mineral_deposits;минералы> из залежей, которые обычно недоступны.<np>
Из-за высоких требований к извлечению минеральных жил из породы экскаватор представляет собой сложную машину, для работы которой требуется <config;i;machines.excavator.consumption> Flux/тик.<br>
Добыча минералов начинается с нижней части ротора, а материалы выводятся из задней части экскаватора.<br>
Три разъема для подключения энергии расположены сбоку, а на задней панели расположена редстоуновая панель управления.<br>
По мере того, как экскаватор выкапывает руду, минеральная жила истощается, а максимальное добываемое количество блоко руды состовляет <config;i;machines.excavator.yield> штук.<br>
Машина состоит из двух частей: двигателя и ротора, показанных на следующих страницах, ротор крепится к "скобам" двигателя. Всю машину можно сформировать нажав правой кнопкой мыши, держа инженерный молот, на задний центральный тяжелый инженерный блок.<br>
<&wheel>Ротор может быть сформирован отдельно с помощью инженерного молота нажав на центральный стальной блок.
<&engine>Двигатель может быть сформирован отдельно с помощью инженераного молота нажав на тяжелый инженерный блок сзади посередине. Если ротор и двигатель построены правильно, то одно нажатие на этот блок сформирует обе части сразу.
