<&items>Промышленная конопля - очень универсальное растение, которое находит применение во всех инженерных профессиях. Его семена можно использовать для создания растительного масла, используемого в <link;industrial_fluids;биодизеле;biodiesel>; его волокна можно использовать для создания §2прочной ткани§r.<br>
Семена можно получить, срывая высокую траву и другими подобными способами.<np>
<&fabric_recipe>Прочная ткань - это эластичное полотно, изготовленное из волокна конопли. Обработав ее можно использовать для создания <link;this;искусственной кожи;ersatz_leather>.<br>
Сама по себе она может быть использована для создания <link;kinetic_generators;паруса;sail_recipe>, <link;balloon;воздушного шара;start>, <link;hempcrete;костробетона>, и <link;this;подушки безопасности;cushion_recipe>.<np>
<&cushion_recipe>Подушка безопасности - это простой блок, изготовленный из прочной ткани и наполненный воздухом. Она способна поглощать удары и предотвращать повреждения при падении, но, в отличие от блоков из слизи, не вызывает отскока.<np>
<&ersatz_leather>Искусственная кожа создается путем пропитки прочной ткани растительным маслом или пчелиным воском. Эта водонепроницаемая ткань может быть использована для изготовления многих изделий из обычной кожи животных, таких как <link;conveyor_belts;конвейерные ленты>.
