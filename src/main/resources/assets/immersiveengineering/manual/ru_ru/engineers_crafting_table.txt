Инженерный верстак
Для различных проектов
Инженерный верстак — это простое улучшение обычного верстака. В дополнение к столешнице из обработанной древесины, он сохраняет ингредиенты внутри сетки крафта при закрытии.
Верстак также имеет небольшой ящик для хранения некоторых ваших компонентов для крафта.
