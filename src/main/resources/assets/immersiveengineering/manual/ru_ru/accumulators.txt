Аккумуляторы
Энергия с собой
<&recipes>§lАккумуляторы§r служат для хранения энергии. На каждую сторону можно подключить только один коннектор, соответствующий напряжению аккумулятора.

Стороны можно настраивать молотом инженера: синий цвет соответствует входу, оранжевый — выходу, а отсутствие цветовой маркировки означает, что сторона полностью закрыта для подключения.

Если щёлкнуть по стороне, присев (Shift), будет настроена противоположная сторона.
