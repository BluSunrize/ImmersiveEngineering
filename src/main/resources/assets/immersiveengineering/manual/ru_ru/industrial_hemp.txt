Промышленная конопля
530 ткани
<&items>Промышленная конопля — очень универсальное растение, применяемое во всей инженерной профессии. Её семена можно использовать для получения растительного масла, применяемого в <link;industrial_fluids;биодизеле;biodiesel>; её волокна можно использовать для создания прочного полотна — §2прочной ткани§r.<br>
Семена можно получить, ломая высокую траву и похожими способами сбора.<np>
<&fabric_recipe>Прочная ткань — стойкое переплетение из волокна конопли. После водоотталкивающей обработки её можно использовать как <link;this;искусственную кожу;ersatz_leather>.<br>
Сама по себе она используется для создания <link;kinetic_generators;улучшенных ветряных мельниц;sail_recipe>, а также <link;balloon;воздушных шаров;start>, <link;hempcrete;костробетона> и <link;this;подушек для прыжков;cushion_recipe>.<np>
<&cushion_recipe>Подушки для прыжков — простые блоки из прочной ткани, надутые воздухом. Они способны поглощать удары и предотвращать урон от падения при приземлении на них, но, в отличие от слизневых блоков, не заставляют упавший объект отскакивать.<np>
<&ersatz_leather>Искусственная кожа создаётся путём насыщения прочной ткани растительным маслом или пчелиным воском. Эту водостойкую ткань можно использовать во многих вещах, где обычно применяется животная кожа, например в <link;conveyor_belts;конвейерных лентах>.
