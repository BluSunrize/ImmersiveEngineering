Сборщик
Ну же соберись
<&multiblock>Сборщик - это сложная машина, способная крафтить различные предметы так же, как это делает игрок.<br>
Чтобы сформировать машину, постройте её в соответствии с демонстрацией выше, а затем нажимте правой кнопкой мыши по конвейеру направленному внутрь держа инженерный молот<np> 
Сборщик может содержать в себе 3 рецепта и будет крафтить по ним в порядке слева направо. Готовые предметы могут быть использованы в следующих рецептах.<br>
Три ячеистой сетки хранят рецепт, а 18 слотов снизу хранят ресурсы.<br>
Ниже входа для рисурсов находится вход для жидкостей, через который можно заполнить три внутренние цистерны.<br>
Жидкость из цистерн можно использовать в крафтах для замены таких тар как ведро. Для использования жидкости поместите в рецепт ведро с нужной жидкостью.<br>
Питание машины происходит через разъем находящийся сверху посередине, а подача редстоун сигнала осуществляется через два редстоун разъема по бокам.
