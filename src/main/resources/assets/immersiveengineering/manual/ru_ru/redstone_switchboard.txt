Редстоуновый коммутатор
Осмысленные соединения
При работе с несколькими сетями редстоуновых проводов соединение отдельных цветов друг с другом может требовать много места.<br>
Редстоуновый коммутатор решает эту проблему, позволяя передавать любые сигналы из одной сети в другую, свободно переназначая цвета по пути.<br>
Сигналы проходят только в одном направлении: слева направо, если стоять перед коммутатором.<br>
Кроме того, коммутатор имеет аналоговые инверторы для всех сигналов, позволяя отправлять в выходную сеть инверсию входного сигнала.<np>
Чтобы настроить коммутатор, используйте отвёртку инженера для открытия интерфейса. Щёлкните по любому входному разъёму, чтобы начать подключение кабеля, затем щёлкните по выходному разъёму, чтобы завершить соединение.<br>
При необходимости включите или выключите красную кнопку «инвертировать» на любой выходной панели — но учтите, что инверсия имеет эффект только если к этому выходу есть соединение.
