Револьверные патроны

Патроны создаются на инженерном верстаке с использованием специальных <link;blueprints;чертежей>. Чертежи для обычных патрон вы можете создать сами, но для некоторых более продвинутых типов потребуется приобрести соответствующие чертежи у <link;other_engineers;другого инженера>.<np>
<&empty>§lГильза§r и §lгильза для дроби§r - это основа для каждого патрона. Гильзы можно изготовить на <link;metal_press;штамповочном прессе>, используя форму гильзы, что сокращает расход меди. Аналогичным образом, гильза для дроби может быть изготовлена из <link;resin_and_duroplast;фенольной смолы;empty_shell> на разливочном аппарате.<np>
<&casull>§lОбычный патрон§r создается с помощью чертежа "Обычные патроны". Это простая свинцовая пуля, наносящая средний урон.<np>
<&ap>§lБронебойный патрон§r создается по этому же чертежу. Они наносят такой же урон, но пробивают броню из-за больщей кинетической силы.<np>
<&buckshot>§lДробовой патрон§r создается по вышеупомянутому чертежу, представляет собой несколько небольших дробинок, которые при выстреле формируют форму конуса. Этот патрон очень эффективен на короткой дистанции.<np>
<&silver>§lСеребряный патрон§r, также создается с помощью чертежа "Обычные патроны", состоят из свинцовой сердцевины, обернутой серебром, что делает их очень эффективными против нежити.<np>
<&he>§lФугасный патрон§r создается с помощью чертежа "Особые патроны". При попадании патрон взрывается, нанося урон живым существам и разрушая местность.<np>
<&dragon>§lПатрон 'Дыхание дракона'§r создается с помощью чертежа "Особые патроны". Как и дробовой патрон, он эффективен на близком расстоянии, но вместо мелкой дробт он наполнен легковоспламеняющейся металлической крошкой, создающей вспышку пламени.<np>
<&potion>§lЗельевой патрон§r тоже создается с помощью чертежа "Особые патроны". Его можно наполнить зельем при размещении патрона и зелья в сетке крафта. Обычные зелья срабатывают при попадании, взрывные зелья имеют поражающую область и туманные зелья будут создавать временное облако с эффектом.<np>
<&flare>§lСигнальный патрон§r создается с помощью чертежа "Особые патроны". При выстреле сигнальная ракета взрывается на определенном расстоянии, а затем медленно падает на землю. Вы можете покрасить его положив патрон и краситель на крафтовую сетку, это изменит его цвет.<np>
<&homing>§lСамонаводящийся патрон§r создается с помощью чертежа "Особые патроны". Используя интригующие свойства "Ока Эндера", эти снаряды приобретают способность находить ближайшую цель и преследовать ее. Они не будут нацелены на игроков одной команды или животных, прирученных стрелком или его сокомандниками.
<&wolfpack>§lПатрон 'Волчья стая'§r создан по тому же чертежу из нескольких самонаводящихся пуль в одном патроне. Первая пуля не наводится сама, но при попадании разделяется на шесть самонаводящихся пуль, попадающих в окружающих враждебных существ. Эти пули также усиливают находящихся поблизости прирученных волков, увеличивая их скорость и наносимый урон.
