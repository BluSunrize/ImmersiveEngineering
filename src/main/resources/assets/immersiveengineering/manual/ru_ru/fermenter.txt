Ферментатор
Скуль!
Ферментатор — это многоблочная структура, которая извлекает этанол из определённых фруктов, зёрен и овощей через процесс ферментации. Структура строится, как показано выше, и формируется с помощью инженерного молотка на центральном котле, на стороне порта красного камня.<br>
Предметы могут быть введены в ферментатор через два люка сзади, которые помечены синими точками. Люк с оранжевой точкой служит для вывода предметов, а блок под ним — для вывода жидкостей.<br>
Подача сигнала красного камня на панель управления спереди остановит процесс машины, это поведение может быть инвертировано с помощью инженерной отвёртки.<np>
