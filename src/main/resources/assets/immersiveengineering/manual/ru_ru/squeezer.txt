Выжиматель
Нажимные дела
Выжиматель — это многоблочная структура, которая выжимает сок или масло из органических материалов с помощью большого поршня. Структура строится, как показано выше, и формируется с помощью инженерного молотка на центральной деревянной бочке, на стороне порта красного камня.<br>
Предметы могут быть введены в выжиматель через два люка сзади, которые помечены синими точками. Люк с оранжевой точкой служит для вывода предметов, а блок под ним — для вывода жидкостей.<br>
Подача сигнала красного камня на панель управления спереди остановит процесс машины, это поведение может быть инвертировано с помощью инженерной отвёртки.<np>
