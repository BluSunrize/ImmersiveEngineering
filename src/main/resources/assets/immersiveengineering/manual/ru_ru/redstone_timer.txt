Редстоун-таймер
Тик-так, тик-так!
Таймер — это устройство из красного камня, которое использует колеблющийся кварцевый кристалл для вывода сигнала через равные промежутки времени.<br>
Использование инженерной отвёртки на таймере позволяет настроить его интервал и цвет выходного сигнала.<np>
Кроме того, таймер может быть настроен на требование управляющего сигнала, при котором он не будет работать без высокого уровня этого сигнала.
