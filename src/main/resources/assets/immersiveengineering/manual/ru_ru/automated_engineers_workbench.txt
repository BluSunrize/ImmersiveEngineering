Автоматический верстак
Для тех, кто не умеет водить механику
<&multiblock>Автоматизированный верстак — один из первых крупных успехов инженерии малого масштаба.<br>
Машина способна следовать набору инструкций, описанных <link;blueprints;чертежом;start>, для сборки предметов, детализированных в нём.<np>
После сборки многоблочной структуры чертёж может быть размещён на её чертёжном столе. После выбора предмета, который должен быть создан, машина начнёт процесс сборки. Для работы машины потребуется снабжение материалами и энергией.<br>
Входы предметов — это два люка, помеченные синими точками, вход энергии находится над ними. Готовые предметы выбрасываются в конце конвейерной ленты.<br>
Подача сигнала красного камня на панель управления под чертёжным столом остановит процесс машины, это поведение может быть инвертировано с помощью инженерной отвёртки.
