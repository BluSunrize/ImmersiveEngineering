Логический элемент
Полный по Тьюрингу
<&unit>Благодаря универсальности <link;redstone_wiring;редстоуновых проводов> и коммутации через <link;crafting_components;электронные лампы;tubes> сложный редстоун можно сжать в <link;engineers_circuit_workbench;логические схемы>.<br>
Логический элемент — специализированная машина, в которую устанавливаются логические схемы для работы.<br>
В нём достаточно места для §210 схем§r, а также есть полные §28 встроенных регистров§r, доступных для любой схемы.<br>
Чтобы логический элемент взаимодействовал с цветными редстоуновыми системами, к его стороне должен быть подключён <link;redstone_wiring;редстоуновый интерфейсный коннектор;bundled>.<br>
Каждый раз, когда любой из подключённых коннекторов меняет состояние, логический элемент проходит по своим схемам и выполняет все 10 операций.<br>
Если схема использует регистр как выход, полученное значение сохраняется в регистре и может использоваться следующей схемой как вход.<br>
Тот же интерфейсный коннектор, который используется для ввода, можно использовать и для вывода.
