Дизельный генератор
Больше объема!
Электрическая сеть бесполезна без мощного источника. Дизельный генератор — основной метод получения ВН-энергии. Он работает на <link;industrial_fluids;биодизеле> или другом тяжелом топливе.<np>
<&structure>Собирается из радиаторов, труб, блоков и лесов. Активируется молотом по центральному генератору.<br>
Топливо подается в нижние углы, энергия выводится через три порта сверху.<br>
Генератор выдает <config;i;machines.dieselGen_output> Flux/t, распределяя их между портами. Он работает только тогда, когда энергия может быть принята.<br>
Редстоун может останавливать его (настраивается отверткой).
