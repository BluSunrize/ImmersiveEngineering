<&recipe>Дозатор предметов предназначен для сбора набора предметов из входящего конвейера перед отправкой их дальше, чтобы передавать оптимизированные размеры партий технике.<np>
В §2пакетированном режиме§r входящие предметы будут приниматься в инвентарь непосредственно под фильтрами, и собранная партия будет выведена только когда все фильтры удовлетворены.<br>
Как только выходной режим устройства был изменён на §2одиночный режим§r, любой предмет, который удовлетворяет его отфильтрованному количеству, будет выведен вместо этого.<br>
Соединения под фильтрами буфера устанавливают целевой цвет <link;redstone_wiring;провода из красного камня> через прикреплённые <link;redstone_wiring;Интерфейсные разъёмы красного камня;bundled>.<br>
Когда каждый отдельный фильтр удовлетворён, высокий сигнал на его настроенном цвете будет отправлен через разъём.<br>
Обратите внимание, что если несколько фильтров используют один цвет, все должны быть удовлетворены для вывода сигнала.<br>
Эти сигналы могут использоваться для настройки техники, дисплеев или других устройств для управления целыми фабриками.
