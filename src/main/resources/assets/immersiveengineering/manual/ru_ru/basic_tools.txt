Основные инструменты
Молот и §mСерп§r Отвертка
<&engineers_hammer>Инженерные молоты — один из важнейших инструментов в арсенале инженера.<br>
Его можно использовать для настройки и сборки машин, а также для дробления руды.<np>
<&wirecutters>§lКусачки инженера§r используются для удаления всех проводов, подключенных к блоку, простым щелчком правой кнопкой мыши.<br>
Кусачки также могут удалять провода, натянутые между столбами, при взаимодействии с ними.<np>
<&screwdriver>Инженерные отвертки — еще один обычный предмет в ящике с инструментами.<br>
Они используются для точной конфигурации определенных узлов оборудования.<np>
<&multimeter>§lМультиметры§r используются для измерения соединений.<br>
Наведение его на любой накопитель энергии или щелчок правой кнопкой мыши покажет текущий уровень заряда.<br>
Shift + ПКМ по двум соединителям позволит рассчитать средние потери между ними.<br>
Мультиметры также можно использовать для считывания уровней редстоуна в таких блоках, как редстоун-коннекторы и редстоун-пыль.
