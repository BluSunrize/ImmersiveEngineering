Экскаватор
Лучше, чем гномы
<&full>Экскаватор является одним из пиков современной промышленности, способный выкапывать <link;mineral_deposits;минералы> из жил, обычно недоступных.<np>
Из-за интенсивных требований по извлечению разреженных жил из скалы, экскаватор — это сложная машина, которая требует <config;i;machines.excavator.consumption> Флакс/т для работы.<br>
Добыча начинается с нижнего кончика роторного колеса, а материалы выводятся с задней части кронштейна двигателя.<br>
Три разъёма для двигателя принимают энергию с боку, а сзади находится панель управления редстоуном.<br>
По мере того как экскаватор выкапывает руды, добыча жилы медленно уменьшается, но минеральное месторождение может обеспечить максимум <config;i;machines.excavator.yield> блоков руды.<br>
Структура состоит из двух частей: двигателя, показанного на следующей странице, и роторного колеса, отображённого на следующей, которое помещается в "скобы" двигателя. Полная структура может быть собрана с помощью инженерного молотка на заднем центральном блоке тяжёлой инженерной стали.<br>
<&wheel>Колесо может быть сформировано само по себе с помощью инженерного молотка на центральном стальном блоке.
<&engine>Двигатель может быть сформирован сам по себе через задний центральный порт блока тяжёлой инженерной стали, и он сформирует роторное колесо с ним, при условии, что оно размещено правильно.
