Термоэлектрический генератор
Горячее и холодное
<&recipe>Термоэлектрические генераторы — это ещё один вид генерации энергии, работающий без использования каких-либо механических деталей. Эти генераторы используют температурный градиент между двумя противоположными источниками для производства энергии.<np>
Размещение источника тепла с одной стороны и более холодного источника с противоположной стороны генерирует энергию на основе разницы между двумя температурами.<br>
Любая жидкость будет работать на основе своей температуры, вместе с некоторыми другими блоками.<br>
Температурные градиенты используются только через генератор, а не через соседние стороны.<np>
