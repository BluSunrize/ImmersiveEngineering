Внешний нагреватель
Готовка с помощью flux!
<&recipe>Внешний нагреватель генерирует тепло из Flux энергии, тепло излучается из решеток по бокам.<br>
Его невозможно использовать для нагревания воздуха в доменной печи, копчения еды и использования в плавильной печи.<br>
При размещении рядом с обычной печью эта тепловая энергия будет обеспечивать нагрев печи без потребления топлива.<br>
Нагреватель можно вращать используя инженерный молот, присядтье при размещении блока, что бы сторона с разъемом смотрела в противоположную вашему взгляду сторону.<br>
Нагреватель потребляет 8 Flux/тик за каждую работающую печь. Для нагрева печи до максимальной температуры он использует в четыре раза больше энергии, пока печь не достигнет максимальной температуры.<br>
Пока температура в печи максимальна, внешний нагреватель будет потреблять §o32 Flux/тик§r за каждую печь ускоряя её работу, ускорение возможно отключить подав редстоун сигнал.<br>
Нагреватель будет работаь только в том случае, если печь не пуста.
