Проходные изоляторы
Таверна «Дыра в стене»
<&feedthrough>Сами по себе провода не могут сосуществовать с камнем, деревом или более промышленными материалами, перекрывающими им путь.<br>
При аккуратном применении терракотовой изоляции внутри этих материалов можно создать прочный канал для проведения энергии.<br>
Проходной изолятор позволяет объединить два коннектора через стену толщиной в один метр и не может подключать более одного провода к каждому коннектору.<br>
Их можно создавать с любым «обычным» цельным блоком посередине, щёлкнув молотом инженера по любому из двух коннекторов.<br>
Неструктурные коннекторы можно использовать для создания проходных изоляторов соответствующего типа провода.
