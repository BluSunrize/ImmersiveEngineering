Штамповочный пресс
Давящее ощущение
<&multiblock>Штамповочный пресс - это автоматизированный способ формования металла. В нем используется поршень высокого давления для штамповки пластин, стержней или других металлических деталей с помощью специальных форм.<br>
Машина формируется, как показано выше, используя на поршне инженерный молот .<np>
Энергия подается через разъема в верхней части, а изделия проходят по конвейеру в направлении движения.<br>
Нижний средний блок - это порт редстоун управления, нажав правой кнопой мыши, держа инженерную отвертку, по нему можно инвертировать контроль.<np>
<&mold_blueprint>Для работы пресса к поршню должна быть прикреплена форма. Эти формы создаются на <link;engineers_workbench;§o§nинженерном §o§nверстаке§r> используя чертеж, показанный выше.<np>
<&mold_recipes>Формы изготовляются как показано выше, при этом при каждом создании формы инженерные кусачки получают урон. Затем форма помещается на пресс нажатием правой кнопки мыши по прессу, держа в руке форму.<np>
<&packing>Формы для упаковки и распаковки можно использовать для упаковки 4 или 9 одинаковых предметов в удобую форму для хранения, а также для их повторной распаковки. Их можно использовать для хранения слитков в виде блоков или для автоматического создания простых блоков, таких как песчаник.
