Редстоуновый таймер
Тик-так, тик-так!
Таймер — редстоуновое устройство, использующее колеблющийся кварцевый кристалл для выдачи сигнала через равные промежутки времени.<br>
Использование отвёртки инженера по таймеру позволяет настроить интервал и цвет выходного сигнала.<np>
Кроме того, таймер можно настроить на требование управляющего сигнала; в этом случае он не будет работать, пока этот сигнал не активен.
