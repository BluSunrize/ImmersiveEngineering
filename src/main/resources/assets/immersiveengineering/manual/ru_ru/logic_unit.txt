Системный блок
Продолжение Тьюринга
<&unit>Благодаря универсальности <link;redstone_wiring;редстоуновых проводов> и гибкости <link;crafting_components;радиоламп;tubes>, сложные редстоун схемы могут быть воссозданны в <link;engineers_circuit_workbench;логических платах>.<br>
Системный блок - это специальная машина, в которой используются логические платы.<br>
В нем достаточно места для размещения §210 плат§r, и он оснащен §28 регистрами§r, которые можно использовать для любой платы.<br>
Чтобы системный блок мог взаимодействовать с цветными редстоун системами, к нему сбоку должен быть прикреплен <link;redstone_wiring;редстоуновый интерфейсный коннектор;bundled>.<br>
Каждый раз, когда какой-либо из подключенных разъемов меняет свое состояние, системный блок переключается между своими платами и выполняет все 10 операций.<br>
Если плата использует регистр в качестве выходного сигнала, результирующее значение сохраняется в регистре и может быть использовано последующей платой в качестве входного сигнала.<br>
Один редстоуновый интерфейсный коннектор может использоваться как для водда, так и для вывода.
