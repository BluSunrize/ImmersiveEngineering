Редстоуновый коммутатор
Значимые связи
При работе с несколькими проводными редстоун сетями для соединения отдельных цветов друг с другом может потребоваться много места.<br>
Редстоуновый коммутатор устраняет эту проблему, позволяя передавать любые сигналы из одной сети в другую, при этом цвета могут быть свободно изменены в процессе передачи.<br>
Сигналы передаются только в одном направлении: слева -> направо, если смотреть на дверцу коммутатора.<br>
Кроме того, коммутатор оснащен аналоговыми преобразователями для всех сигналов, что позволяет инвертировать выходной сигнал.<np>
Чтобы настроить коммутатор, откройте интерфейс с помощью инженерной отвертки. Щелкните по любому из входных разъемов, чтобы начать подключать кабель, затем щелкните по выходному разъему, чтобы завершить подключение.<br>
При необходимости инвертировать сигнал, нажмите красную кнопку "инвертировать" на любой из панелей вывода, инверсия будет действовать только при наличии подключения к этому выходу.
