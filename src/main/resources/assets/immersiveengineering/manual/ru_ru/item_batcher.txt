Дозатор предметов
Ну-ка, все вместе
<&recipe>Дозатор предметов предназначен для сбора предметов с подающего конвейера перед отправкой их дальше, чтобы оптимизировать размеры партий для дальнейшей отправки машинам.<np>
В режиме §2всех фильтров§r, входящие предметы будут приниматься в инвентарь непосредственно под фильтрами, а собранная партия будет отправлена только тогда, когда соблюдены условия всех фильтров.<br>
Как только режим вывода устройства будет настроен на §2индивидуальные фильтры§r, будет выводить те предметы, у которых соблюдены условия индивидуального фильтра.<br>
Редстоун сигнал под фильтром задает цветовой сигнал, передаваемый <link;redstone_wiring;редстоуновым проводом> через подключенный <link;redstone_wiring;редстоуновый интерфейсный коннектор;bundled>.<br>
Когда каждый отдельный фильтр будет соблюден, через коннектор будет передан цветовой редстон сигнал.<br>
Обратите внимание, что если несколько фильтров используют один и тот же цвет, то для получения выходного сигнала все они должны быть соблюдены.<br>
Эти сигналы могут быть использованы для настройки оборудования, дисплеев или других приспособлений для управления целыми фабриками.
