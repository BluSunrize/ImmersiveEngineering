Инженерный верстак
Вечно завален вещами
Профессиональный стол для создания предметов по чертежам. Положите чертеж слева, ингредиенты в центре, и заберите результат справа.<np>
Вторая функция — модификация инструментов (бура, щита, револьвера). Положите инструмент в основной слот, чтобы открыть слоты для улучшений.
