Экскаватор
Лучше гномов
<&full>Экскаватор — одна из вершин современной промышленности, способная добывать <link;mineral_deposits;полезные ископаемые> из жил, обычно недоступных.<np>
Из-за сложностей извлечения разреженных жил из породы экскаватор является сложной машиной, которой для работы требуется <config;i;machines.excavator.consumption> Flux/t.<br>
Добыча начинается с нижнего края ковшового колеса, а материалы выводятся сзади кронштейна двигателя.<br>
Три разъёма двигателя принимают энергию сбоку, а сзади расположена панель редстоунового управления.<br>
По мере добычи руд выход жилы постепенно уменьшается, но месторождение может дать максимум <config;i;machines.excavator.yield> блоков руды.<br>
Конструкция состоит из двух частей: двигателя, показанного на следующей странице, и ковшового колеса, показанного далее; колесо вставляется в «скобы» двигателя. Полную конструкцию можно собрать, использовав молот инженера по заднему центральному тяжёлому инженерному блоку.<br>
<&wheel>Колесо можно сформировать отдельно, использовав молот инженера по центральному стальному блоку.
<&engine>Двигатель можно сформировать отдельно через тяжёлый инженерный блок заднего центрального порта; при правильном размещении он сформирует вместе с собой и ковшовое колесо.
