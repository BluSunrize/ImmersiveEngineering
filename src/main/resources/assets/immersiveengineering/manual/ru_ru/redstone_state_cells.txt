Редстоуновый переключатель
4-разрядная память
Редстоуновый переключатель - это компонент, используемый с <link;redstone_wiring;редстоуновыми проводами>. Он сохраняет входное значение и затем будут выводить это же значение до тех пор, пока не будет сброшено.<br>
Если раньше для таких настроек требовалось несколько компараторов или даже поршней, то теперь можно сохранить значение в одной <link;crafting_components;радиолампе;tubes>.<np>
При нажатии правой кнопки мывши, держа инженерную отвертку, по редстоуновому переключателю открывается интерфейс для настройки цветов установочного, сбрасывающего и выходного сигналов.<br>
§lУстановочный: §rСигнал этого цвета сохраняется в переключателе, пока не будет сброшен.
§lСбрасывающий: §rСигнал этого цвета будет сбрасывать установочный сигнал, позволяя заново его назначить.
§lВыходной: §rСигнал этого цвета будет выводиться.<br>
Если установочный и сбрасывающий сигналы одного цвета, то переключатель будет работать в режиме залипания, при каждом нажатии выходной сигнал либо будет отправляться, либо нет.
