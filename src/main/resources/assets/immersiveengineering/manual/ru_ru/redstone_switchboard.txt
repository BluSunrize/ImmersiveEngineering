Редстоун-коммутатор
Осмысленные соединения
При работе с несколькими сетями проводов из красного камня подключение отдельных цветов друг к другу может в итоге потребовать много места.<br>
Редстоун-коммутатор облегчает эту проблему, позволяя любым сигналам из одной сети передаваться в другую, при этом цвета свободно переназначаются по пути.<br>
Сигналы проходят только в одном направлении; слева -> направо, когда стоишь перед коммутатором.<br>
Кроме того, коммутатор имеет аналоговые инверторы для всех сигналов, позволяя выходной сети получать инверсию входного сигнала.<np>
Чтобы настроить коммутатор, используйте инженерную отвёртку для открытия интерфейса. Нажмите на любое из входных гнёзд, чтобы начать подключение кабеля там, затем нажмите на выходное гнездо, чтобы завершить соединение.<br>
Опционально, переключите красную кнопку "инвертировать" на любом из выходных панелей включено или выключено — хотя обратите внимание, что инверсия имеет эффект только если есть соединение, идущее к этому выходу.
